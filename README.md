# J.A.R.V.I.S. — Windows · Mac 개인비서

말로 부르면 메일, 일정, 카카오톡, 문서, 내 컴퓨터를 대신 처리해 주는 자비스 스타일 개인비서입니다.

- **음성**: "자비스"라고 부르거나 `Alt+J`(Mac은 `Option+J`)를 누르고 말하면 됩니다. 한국어 음성 인식(Whisper)은 내 컴퓨터에서 돌아가고, 답변은 음성으로 읽어 줍니다.
- **두뇌**: Claude (기본 `claude-opus-5-5`)
- **할 수 있는 일**
  - Gmail: 메일 검색·읽기·요약, 메일 쓰기와 보내기(임시보관도 가능)
  - 구글 캘린더: 일정 조회·추가·삭제
  - 카카오: 톡캘린더 일정 조회·추가·삭제, "나와의 채팅"으로 보내기 (공식 API)
  - 카카오톡: 친구·단톡방에 메시지 보내기 (PC 카톡 앱 조작), Mac은 채팅 읽기도 가능
  - 문서: 워드(.docx), 마크다운, 텍스트 문서 만들기, 구글 문서 만들기
  - 기억: "내 차 번호 기억해" 같은 정보를 저장하고 나중에 꺼내 쓰기
  - 알림: "3시에 회의 알려줘" → 데스크톱 알림 + 음성
  - PC 조작: 앱 실행, 웹·파일 열기, 클립보드, 터미널 명령 실행
- **안전장치**: 메일·카톡 보내기, 명령 실행, 일정 삭제는 실행 전에 확인 창이 뜹니다. API 키와 로그인 정보는 OS 보안 저장소로 암호화해서 저장합니다.

## 1. 설치하기

### 방법 A: 설치 파일 받기 (추천)
1. GitHub 저장소의 **Actions** 탭 → **Build installers** → **Run workflow**를 누릅니다.
2. 10~15분 뒤 완료된 실행을 열고 맨 아래 **Artifacts**에서 내려받습니다.
   - Windows: `jarvis-windows-latest` 안의 `.exe`를 실행
   - Mac: `jarvis-macos-latest` 안의 `.dmg`를 열고 Applications로 끌어다 놓기
3. 서명되지 않은 앱이라 처음 실행할 때 경고가 나옵니다.
   - Windows: "Windows의 PC 보호" → **추가 정보** → **실행**
   - Mac: 앱을 **오른쪽 클릭 → 열기** → **열기**

> Mac 설치 파일은 Apple Silicon(M1 이상)용입니다. 인텔 Mac은 방법 B로 실행하세요.

### 방법 B: 소스로 바로 실행
[Node.js 22](https://nodejs.org)를 설치한 뒤 터미널에서:

```bash
git clone <이 저장소 주소>
cd jarvis
npm install
npm start
```

처음 실행하면 음성 인식 모델(약 250MB)을 한 번 내려받습니다. 화면 아래 상태에 진행률이 보이고, 끝나면 오른쪽 위 **VOICE** 불이 켜집니다.

## 2. Claude API 키 넣기 (필수)

1. [Claude 콘솔](https://platform.claude.com/settings/keys)에 로그인해서 **Create Key**로 키를 만듭니다. 결제 수단 등록이 필요합니다.
2. 자비스 오른쪽 위 **톱니바퀴(설정)** → **Claude API 키**에 붙여넣고 **저장**.
3. 오른쪽 위 **CLAUDE** 불이 초록색이면 준비 끝입니다. "자비스, 안녕"이라고 말해 보세요.

**비용 참고**: Opus 5.5는 입력 100만 토큰당 $4, 출력 100만 토큰당 $20입니다. 평범한 대화 한 번은 보통 몇 원~수십 원 수준이고, 메일 여러 통을 읽고 요약하면 더 듭니다. 설정의 "생각 깊이"를 `low`로 두면 빠르고 저렴합니다.

## 3. 구글 연결 (Gmail · 캘린더 · 문서)

구글은 개인용 앱도 "OAuth 클라이언트"를 직접 만들어야 합니다. 처음 한 번만 하면 됩니다 (약 10분).

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다 (이름 예: `jarvis`).
2. **API 및 서비스 → 라이브러리**에서 아래 3개를 각각 검색해 **사용 설정**:
   - Gmail API
   - Google Calendar API
   - Google Docs API
3. **API 및 서비스 → OAuth 동의 화면**(Google Auth Platform):
   - 사용자 유형 **외부**, 앱 이름 `Jarvis`, 내 이메일 입력
   - **대상(테스트 사용자)**에 내 Gmail 주소 추가
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**:
   - 애플리케이션 유형 **데스크톱 앱**
   - 만들어진 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사
5. 자비스 설정 → 구글 칸에 두 값을 넣고 **구글 연결** → 브라우저에서 내 계정 선택 → "확인되지 않은 앱" 화면에서 **고급 → Jarvis(으)로 이동** → 권한 허용.

> **7일마다 다시 로그인해야 한다면**: OAuth 동의 화면이 "테스트" 상태이면 구글이 7일 뒤 로그인을 만료시킵니다. **앱 게시(프로덕션으로 푸시)**를 누르면 해결됩니다. 나만 쓰는 앱이라 구글 심사를 받지 않아도 되고, 로그인할 때 "확인되지 않은 앱" 경고만 한 번 더 보입니다.

## 4. 카카오 연결 (톡캘린더 · 나에게 보내기)

1. [카카오 Developers](https://developers.kakao.com/)에 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**.
2. **앱 키**에서 **REST API 키**를 복사합니다.
3. **카카오 로그인 → 활성화 설정 ON**, **Redirect URI**에 아래 주소를 그대로 등록:
   ```
   http://localhost:5781/oauth/kakao
   ```
4. **카카오 로그인 → 동의항목**에서 아래 두 항목을 **사용**으로 설정:
   - 카카오톡 메시지 전송 (`talk_message`)
   - 톡캘린더 (`talk_calendar`) — 목록에 없거나 비활성이면 카카오 정책상 추가 신청(비즈 앱 전환 등)이 필요할 수 있습니다.
5. (선택) **보안 → Client Secret**을 켰다면 그 값도 복사합니다.
6. 자비스 설정 → 카카오 칸에 REST API 키(와 Client Secret)를 넣고 **카카오 연결** → 동의.

## 5. 친구·단톡방에 카톡 보내기

공식 카카오 API는 친구에게 보내는 기능이 막혀 있어서, 자비스가 **PC 카카오톡 앱을 직접 조작**합니다. 비공식 방식이라 카카오 정책 변경이나 앱 업데이트로 동작이 바뀔 수 있고, 아주 드물게 계정 제한 위험이 있습니다. 처음에는 "나와의 채팅"이나 가족에게 보내 보면서 확인하세요.

- **Windows**: 카카오톡 PC 앱을 켜고 로그인한 상태로 두세요. 자비스가 채팅 목록에서 방 이름을 검색해 메시지를 보냅니다. 카카오톡이 **채팅 탭**에 있으면 가장 잘 됩니다. 채팅방 이름은 정확히 말해 주세요 (예: "엄마에게 카톡으로 저녁 먹었냐고 보내줘").
- **Mac**: [kmsg](https://github.com/channprj/kmsg)를 설치합니다.
  ```bash
  brew install channprj/tap/kmsg
  kmsg status
  ```
  처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 터미널과 JARVIS를 허용하세요. Mac에서는 "엄마 카톡방 최근 메시지 읽어줘"처럼 읽기도 됩니다.

## 6-1. 사람 같은 목소리로 바꾸기 (선택)

기본 음성은 컴퓨터 음성이라 딱딱하게 들립니다. 설정(톱니바퀴) → **음성** → **자비스 목소리**에서 바꿀 수 있어요.

- **OpenAI 사람 같은 음성 (추천)**: 음성 인식용으로 넣은 OpenAI 키를 그대로 씁니다. 목소리는 `onyx`(낮고 묵직한 남성)가 자비스와 가장 비슷합니다. "말투 지시" 칸에 원하는 말투를 글로 적으면 그대로 따라 합니다. 비용은 답변 한 번에 1원 안팎입니다.
- **ElevenLabs (가장 사람 같음)**: [elevenlabs.io](https://elevenlabs.io)에 가입 → 설정 → API Keys에서 키를 만들어 넣으세요. 음성 라이브러리에서 마음에 드는 목소리의 ID를 복사해 넣으면 그 목소리로 말합니다. 무료 구간이 있고, 많이 쓰면 월 구독이 필요합니다.
- 클라우드 음성이 실패하면(인터넷 끊김, 키 오류) 기본 음성으로 대신 읽고 화면에 이유를 한 번 알려 줍니다.

## 6-2. 인터넷 검색과 화면 조작

- **인터넷 검색**: 기본으로 켜져 있습니다. "오늘 서울 날씨 어때?", "엔비디아 주가 찾아봐", "이 근처 맛집 찾아서 브라우저로 띄워줘"처럼 말하면 자비스가 직접 검색해서 읽고 짧게 말해 주거나, 브라우저에 결과를 열어 줍니다. (Claude 검색 요금: 검색 1,000번에 약 10달러)
- **화면 조작 (실험 기능)**: 설정 → 웹 · 화면 조작에서 켭니다. 자비스가 화면을 찍어 보고 사람처럼 마우스를 움직이고 클릭하고 글자를 입력합니다. 예: "크롬 열어서 유튜브에서 아이유 노래 틀어줘", "엑셀 열린 거에서 B열 합계 넣어줘".
  - 시작할 때 한 번 허락을 묻고, 조작하는 동안 자비스 창은 아래로 내려갑니다.
  - 결제·송금·비밀번호 입력·삭제·전송 같은 일은 하기 전에 멈추고 물어봅니다.
  - 도중에 멈추려면 **Alt+Shift+X** (Mac은 **Option+Shift+X**).
  - **Mac**: 처음 한 번 시스템 설정 → 개인정보 보호 및 보안에서 **화면 기록**과 **손쉬운 사용**에 JARVIS를 허용한 뒤 앱을 다시 켜세요.
  - 화면 사진이 Claude로 전송됩니다. 은행·비밀번호 화면이 열린 상태에서는 쓰지 마세요. 작업 한 번에 수십~수백 원 정도 듭니다.
  - 모델이 Opus, Sonnet 5.5/5, Fable일 때만 동작합니다 (Haiku는 안 됨).

## 7. 문제 해결

- **말을 잘 못 알아들어요 / 답이 느려요**: 대화 기록 아래 회색 줄에 "음성 인식 · 첫 답 · 전체" 시간이 나옵니다. 어디가 느린지 보고 아래를 바꿔 보세요.
  - 음성 인식이 느리거나 부정확하면: 설정 → 음성 인식 방식을 **클라우드 OpenAI**로 바꾸고 [OpenAI API 키](https://platform.openai.com/api-keys)를 넣으세요. 한국어 정확도가 크게 좋아지고 1초 안팎으로 빨라집니다 (1분 말하기에 몇 원 수준).
  - 첫 답이 느리면: 설정 → 모델을 **Sonnet 5.5**(빠름)나 **Haiku 5.5**(가장 빠름)로 바꾸거나, Opus를 쓰면서 **빠른 모드**를 켜세요 (요금 2배).
  - 답변은 문장이 완성되는 대로 바로 읽기 시작합니다.
  - 클라우드 인식 모델은 기본이 **가장 정확**(gpt-4o-transcribe)입니다. 사람 이름, 회사명, 앱 이름처럼 자주 틀리는 단어는 설정 → **자주 쓰는 단어**에 쉼표로 적어 두면 더 잘 알아듣습니다.
  - "차비스", "자비쓰"처럼 비슷하게 들려도 호출어로 알아듣습니다.
- **"자비스"라고 불러도 반응이 없어요**: 오른쪽 위 MIC와 VOICE 불을 확인하세요. VOICE가 꺼져 있으면 음성 모델을 내려받는 중입니다. 시끄러운 곳이면 `Alt+J`를 누르고 말하는 편이 정확합니다.
- **인식이 부정확해요**: 설정 → 음성 인식 모델을 `large-v3-turbo`로 바꾸면 더 정확합니다 (메모리 8GB 이상 권장, 처음에 모델 약 800MB 다운로드).
- **한국어 목소리가 어색해요**: Windows는 설정 → 시간 및 언어 → 음성에서 한국어 음성(가능하면 "Natural" 음성)을 추가하세요. Mac은 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성에서 한국어 "유나" 고품질 음성을 내려받으세요.
- **확인 창 없이 바로 실행하고 싶어요**: 설정 → 안전에서 끌 수 있지만, 메일과 카톡이 잘못 나가는 것을 막아 주므로 켜 두는 것을 권합니다.

## 8. 구조 (개발자용)

```
src/
  main/               Electron 메인 프로세스 (Node.js)
    main.js           창, IPC, 단축키, 알림 스케줄러
    agent.js          Claude 도구 사용 루프, 시스템 프롬프트
    stt.js            Whisper 음성 인식 (@huggingface/transformers, 오프라인)
    tts.js            사람 같은 클라우드 음성 (OpenAI / ElevenLabs)
    computer.js       화면 조작 (스크린샷, 마우스·키보드: Windows PowerShell+user32 / Mac CoreGraphics)
    store.js          설정·기억·토큰 저장 (safeStorage 암호화)
    oauth.js          구글·카카오 로그인 (loopback)
    tools/            자비스가 쓰는 도구들
      memory.js  reminders.js  google.js  kakao.js  documents.js  pc.js
  renderer/           화면 (HTML/CSS/JS, 빌드 과정 없음)
    hud.js            홀로그램 코어 애니메이션
    voice.js          마이크, 말소리 구간 감지, TTS
    app.js            음성 흐름, 대화 기록, 설정 창
test/                 node --test 단위 테스트
```
